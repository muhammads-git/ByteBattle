Design/Rules....

Room creation: host creates room → gets shareable link → link stays open, anyone can join, until host presses start
Late joiners: blocked once game has started, shown "room already started"
Host after start: irrelevant — host leaving mid-game has zero effect on other players, the game is self-running once started
Host never starts: room has a global TTL (you said 10 min) — if it expires with no start, room disbands
Game structure: 3 questions per room, each with a countdown, then game ends
End state: all players redirected to a leaderboard, see their rank, then free to leave/create new room
